# ادب‌یار — نسخهٔ آزمایشی

نسخهٔ محدود و رمزدارِ اپلیکیشن «ادب‌یار» که فقط برای ارزیابیِ ظاهر و کارکرد منتشر شده است.

- تنها سه درسِ نمونه از پایهٔ هفتم و یک بخشِ مهارت در آن هست.
- ورود با رمز انجام می‌شود.
- محتوای درسی، حقّ نشرِ محفوظ است؛ بازنشر یا کپی‌برداری مجاز نیست.

این مخزن فقط فایلِ ساخته‌شده را نگه می‌دارد؛ کدِ منبع در مخزنِ خصوصیِ پروژه است.
